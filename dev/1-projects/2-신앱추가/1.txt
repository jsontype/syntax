[새로운 앱을 만들 때마다 진행 해야할 일 절차서]

1. Cloudflare Pages 생성
  https://dash.cloudflare.com
  → Compute → Workers&Pages 에서 깃 레포지토리 임포트로 프로젝트 생성
    - Project name: broodev-xxxx
    - Root directory (advanced): apps/xxxx → Continue to project
  → Custom domains 탭에서 도메인 설정
    - Domain: xxxx.broodev.com → Activate Domain
  → Settings 탭에서 빌드 워치 패스 설정: 
    - Build watch paths: apps/xxxx/* → Enter 키 → Save

1. Google Search Console 등록
  https://search.google.com/search-console/welcome
