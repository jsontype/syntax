[Stripe ④ 구독 운영 (고객 포털 · 갱신 알림 · 실패 처리) · 운영 · 세무 메모]

1. カスタマーポータル (settings/billing/portal)
  사용 ON · サブスクリプションのキャンセル 許可 → 「期間終了時にキャンセル」 (즉시 취소 X — 환불 정책과 일치) · 支払い方法の更新 ON · 請求書履歴 ON · プラン変更 OFF(年額 하나뿐)
  「リンクを有効化」 → 로그인 링크 https://billing.stripe.com/p/login/… → 앱 biz.js 의 PLANS.portal → 요금 FAQ 에 「お客様ポータルを開く」
  포털 로그인은 계정당 하나 — 다른 앱도 같은 링크. 라이선스 메일에도 같은 링크(Functions 의 env PORTAL_URL 로 덮어쓰기 가능)

1. 갱신 리마인더 · 결제 실패 (settings/billing/automatic)
  「更新前にメールを送信」 ON (7일 전) — 약관 · 特商法 표기에 「更新日の前にメールでお知らせ」 라고 적었으므로 필수
  支払い失敗時: Smart Retries ON · 리트라이 전부 실패 시 「サブスクリプションをキャンセル」 · 失敗 메일 ON (고객이 카드를 갱신하게)
  라이선스 서버 쪽: 年額 만료 = Stripe 기간 종료 + 3일 유예 → 재시도 중(past_due)에도 유지, 취소되면 웹훅(subscription.deleted)이 종료

1. 영수증 · T번호
  顧客メール 설정에 「税 ID を表示」 가 있으면 ON. 없어도 영수증 PDF 에 계정 税 ID 가 표시된다 → 실결제 테스트에서 확인

1. 수수료 · 장부
  국내 카드 3.6% · 구독은 Billing +0.7% · Stripe Tax +0.5% · 차지백 ¥1,500 · 買い切り 인보이스 PDF 0.4%(상한 $2)
  입금은 수수료 차감 후 → 장부에는 매출 총액과 支払手数料 를 따로 (残高 → レポート 월별 CSV)

1. 소비세
  일본 고객 매출은 과세(10% 내세) · 해외 고객은 不課税. 적격청구서 발행사업자이므로 신고 필요
  2割特例 는 2026년분까지 → 2027년분부터 簡易課税(제5종 50%) 선택 신고를 2026-12-31 까지 검토
  屋号 공표: 국세청 공표 사이트에 屋号가 나오게 하려면 「適格請求書発行事業者の公表事項の公表(変更)申出書」 (선택)

1. 차지백 · 보존 · 가격 변경 규칙
  환불 페이지에 「메일 먼저」 를 적어 둔다. 분쟁이 오면 대시보드에서 증빙(영수증 · 이용 로그 · 약관 동의 시각 = Checkout 체크박스 기록) 제출
  결제 기록 7년 보존(개인정보 페이지에 그렇게 적음) · Stripe 데이터 + 연 1회 CSV 백업
  가격 · 조건을 바꾸면 ① 법적 정본 biz.js + 앱 biz.js ② Stripe Price 는 새로 만들고 옛 Price 는 アーカイブ(기존 구독자는 옛 가격 유지 · 약관 5조) ③ 약관 15조대로 14일 전 공지
  영수증 · 포털 · Checkout 의 언어는 고객 브라우저에 맞춰 Stripe 가 자동(日/韓/英)

1. 운영 작업 (라이선스 서버와 연동 — 라이선스 노트의 admin API)
  메일 미도착: KV 의 mail_error 확인 → admin resend, 또는 Stripe 웹훅 화면에서 이벤트 Resend (멱등이라 중복 발급 없음)
  기기 3대 초과(PC 교체): admin reset_devices · 고객 스스로는 요금 페이지 「この端末の有効化を解除」
  환불: Stripe 전액 환불 → 웹훅이 자동 무효화. 年額 환불은 구독도 취소한다(안 하면 다음 해 또 청구)
  Stripe 밖 판매(은행 송금 등): admin issue 로 수동 발급
