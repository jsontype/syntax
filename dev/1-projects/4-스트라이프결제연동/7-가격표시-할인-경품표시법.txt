[Stripe ⑦ 가격 표시 — 할인(二重価格表示)과 景品表示法 (2026-10-07)]

1. 무엇을 했나
  평생(買い切り) 플랜을 정가 ¥10,000 → 発売記念価格 ¥5,000(-50%) 로 「보여 준다」. 실제 결제 · Stripe Price · 特商法 販売価格 는 ¥5,000 그대로 — 바뀐 것은 표시뿐
  노출: 요금 페이지 카드(13언어) · 잠금 안내 · 메뉴 배지 -50% / 앱 모달의 플랜 카드 2장 + 상단 안내 스트립 + 내비 배지 / 포털 총람 카드 / 特商法은 실제 금액만

1. 표시 요소 (다른 할인 사이트에서 가져온 설득 장치 — 단, 전부 사실에 기반)
  -50% 태그(액센트 색 · 맥동) · 「発売記念価格 · 期間限定」 (종료일을 넣으면 「あと N 日」)
  취소선 정가 → 강조한 판매가 · 「¥5,000 お得」 · 「年額 2 年分の価格で、ずっと」 (앵커링) · 「いちばんお得」 리본
  小字 「発売記念期間の終了後は ¥10,000 になります」 (将来の販売価格 라는 것을 명시)

1. 景品表示法 — 반드시 지킬 것 (消費者庁 「不当な価格表示についての景品表示法上の考え方」)
  판 적 없는 가격을 「通常価格」 라고 부르지 않는다 — 通常価格 는 「最近相当期間 실제로 판 가격」 으로 읽힌다. 비교 가격은 「将来の販売価格」 로만 → 일본어는 「期間終了後の価格」
  기간이 끝나면 정말로 ¥10,000 으로 팔아야 한다 (막연히 계속 연장 = 有利誤認 · 不当表示). 할인을 다시 하려면 통상가로 판 기간이 있어야
  가짜 마감(리셋되는 타이머) · 근거 없는 「残り N 名」 금지 → 종료일(until)이 null 이면 「期間限定」 만, 날짜는 실제 종료일(일본 시간 23:59 · +09:00 으로 파싱 — 보는 사람의 시간대에 흔들리지 않게)
  Checkout 화면 · 영수증 · 特商法 販売価格 행은 할인 전후 모두 실제 금액(¥5,000)만 — 비교 가격을 쓰지 않는다
  ko 「정가」 · en 「Regular price」 는 일본법 대상이 아니라 그대로. zh 의 「恢复原价」(원래 가격으로 복귀) 같은 표현도 피한다

  13언어 문구의 단일 소스는 JSON 1개 + 생성 스크립트(각 파일의 마커 블록을 멱등 재생성) + 검증 스크립트(언어 수 · 키 · 앵커 · 금액 · 카드 간 플랜 이름 통일 · ja 「通常価格」 부재 · JST 오프셋)
  promo.js 핵심
    var L = PLANS.lifetime, list = L.list != null && L.list > L.price ? L.list : null;   // 정가가 없거나 판매가 이하면 할인 표시 전부 숨김
    var off = list ? Math.round((1 - L.price / list) * 100) : 0, days = null;
    if (list && PLANS.promo.until) { var d = Math.ceil((Date.parse(PLANS.promo.until + 'T23:59:59+09:00') - Date.now()) / 864e5); days = d > 0 ? d : null; }
    each('[data-deal]', function (el) { el.hidden = !list; });
    each('[data-price-list]', function (el) { el.hidden = !list; if (list) el.textContent = yen(list); });
    each('[data-promo]', function (el) { var k = el.getAttribute('data-promo'); el.hidden = !list; if (!list) return;
      if (k === 'tag') { el.textContent = '-' + off + '%'; return; }
      if (k === 'promo_limited' && days != null) k = 'promo_days';
      el.textContent = I18N.t(k, { list: yen(list), price: yen(L.price), save: yen(list - L.price), off: off, d: days }); });
    document.addEventListener('mh:lang', apply);   // 언어 전환 · 조각 삽입 뒤 다시 채움

1. 캠페인 끝내는 날
  ① Stripe 에서 ¥10,000 Price 를 만들어 Payment Link 교체 (옛 Price 는 アーカイブ)
  ② 네 곳의 price/list(포털은 lifetime/lifetime_list) 를 10000/null 로 — 세 앱은 표시가 자동으로 할인 전 상태, 포털 카드도 deal-off 로
  ③ 特商法 販売価格 행 · BIZ.updated 갱신 · 캐시 토큰(?v=) 올림 → 푸시
