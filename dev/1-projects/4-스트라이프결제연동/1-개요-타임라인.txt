  상품: 웹앱의 추가 기능 「프리미엄」(디지털 서비스) — 年額 ¥2,500(자동 갱신) / 買い切り ¥5,000 · 税込 · 카드 결제

  발급: Stripe 웹훅 → Cloudflare Pages Function → 라이선스 키 생성(KV) → Resend 메일 → 고객이 앱에 키 입력 → 잠금 해제
  사이트: 포털 1곳에 법적 문서(特商法 · 약관 · 개인정보 · 환불) + 프리미엄 총람, 앱마다 요금 페이지. 사업자 정보·가격의 단일 소스는 JS 파일 하나(biz.js)
  계정 1개로 여러 앱: 상품/링크만 추가(심사·약관 URL 재사용). 라이선스 서버는 상품명으로 자기 앱 것만 처리
